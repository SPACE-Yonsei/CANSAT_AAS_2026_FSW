# 파라포일 조종 알고리즘 시뮬레이션

지상에서 파라포일 조종 알고리즘을 테스트할 수 있는 시뮬레이션 도구입니다.

## 개요

이 시뮬레이션 도구는 실제 하드웨어 없이 파라포일 조종 알고리즘을 테스트할 수 있습니다:
- GPS 좌표 기반 목표 방향 계산
- IMU heading 기반 회전 각도 계산
- 파라포일 모터 제어 로직 시뮬레이션

## 사용법

### 1. 대화형 시뮬레이션 모드

GPS 좌표와 IMU heading을 직접 입력하여 알고리즘을 테스트합니다:

```bash
python3 simulation/parafoil_sim.py
```

**사용 예시:**
```
🎯 목표 GPS 좌표를 입력하세요:
   목표 위도 (예: 37.5665): 37.5670
   목표 경도 (예: 126.9780): 126.9785

📍 현재 위치와 heading을 입력하세요:
   현재 위도: 37.5665
   현재 경도: 126.9780
   현재 Heading (IMU Yaw, 0-360°): 45.0
```

### 2. 빠른 테스트 모드

미리 정의된 테스트 케이스로 알고리즘을 빠르게 테스트합니다:

```bash
python3 simulation/parafoil_sim.py --test
```

## 알고리즘 설명

### 1. GPS 방위각 계산

Haversine 공식을 사용하여 현재 위치에서 목표 위치까지의 거리와 방위각을 계산합니다:

```python
거리 = Haversine(현재_위도, 현재_경도, 목표_위도, 목표_경도)
방위각 = atan2(위도_차이, 경도_차이)  # 0-360도
```

### 2. 회전 각도 계산

현재 heading (IMU yaw)과 GPS 방위각의 차이를 계산하여 회전해야 할 각도를 구합니다:

```python
회전_각도 = 현재_Heading - GPS_방위각  # -180 ~ +180도로 정규화
```

- **음수**: 왼쪽으로 회전 필요
- **양수**: 오른쪽으로 회전 필요

### 3. 모터 제어 로직

회전 각도에 따라 파라포일 모터를 제어합니다:

- **±15도 이내 (데드존)**: 모터 정지 (직진)
- **15도 초과**: 비례 속도 제어
  - 회전 각도가 클수록 모터 속도 증가
  - 최대 90도 회전 시 전속력

**모터 제어 규칙:**
- 왼쪽 회전: 왼쪽 모터 작동
- 오른쪽 회전: 오른쪽 모터 작동
- 직진: 양쪽 모터 정지

## 출력 정보

시뮬레이션 결과는 다음 정보를 포함합니다:

1. **현재 위치 정보**
   - 위도, 경도
   - 현재 Heading (IMU Yaw)

2. **목표 위치 정보**
   - 위도, 경도

3. **계산 결과**
   - 목표까지 거리 (미터)
   - GPS 방위각 (목표 방향)
   - 회전 필요 각도

4. **모터 제어 정보**
   - 동작 상태 (직진/왼쪽 회전/오른쪽 회전)
   - 모터 펄스 폭 (µs)
   - 모터 속도 (%)

## 예제 시나리오

### 시나리오 1: 목표 지점이 동쪽에 있을 때

```
현재 위치: 37.5665°N, 126.9780°E
목표 위치: 37.5665°N, 126.9785°E
현재 Heading: 0° (북쪽)

결과: 오른쪽으로 90° 회전 필요 → 오른쪽 모터 작동
```

### 시나리오 2: 목표 지점이 북동쪽에 있을 때

```
현재 위치: 37.5665°N, 126.9780°E
목표 위치: 37.5670°N, 126.9785°E
현재 Heading: 270° (서쪽)

결과: 왼쪽으로 약 135° 회전 필요 → 왼쪽 모터 작동
```

## 참고사항

- GPS 좌표는 도(degree) 단위로 입력합니다
- Heading은 0-360도 범위입니다 (0°=북쪽, 90°=동쪽, 180°=남쪽, 270°=서쪽)
- 목표 반경 50m 내에 도달하면 "목표 도달" 메시지가 표시됩니다
- 실제 하드웨어와 동일한 알고리즘을 사용합니다 (`flight_logic/flightlogicapp.py`, `Sensor_Motor/parafoil_motor.py`)
